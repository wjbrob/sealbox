# Sealbox name and logo

The Sealbox source code is free software, and you may use, study, change and share it under its
licences. The **name "Sealbox" and the Sealbox logo** are not covered by those licences. This
policy exists so users can tell official builds from modified ones. People must be able to trust
that something called Sealbox has not been altered, because it is encryption software.

## Allowed without asking

- Distributing **unmodified** official releases, or builds made from an unmodified tagged source
  release, under the Sealbox name. Linux distributions and F-Droid are welcome to do this.
- Referring to Sealbox truthfully: "compatible with Sealbox", "a fork of Sealbox", or articles and
  reviews.

## Requires a different name

- **Modified versions (forks)** must use a different name and logo, and must not suggest they are
  official or endorsed. You may say "based on Sealbox".
- Running a public service built from modified server code under the Sealbox name.

If you're unsure, open an issue and ask.
