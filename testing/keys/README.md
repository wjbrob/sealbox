# testing/keys — TEST signing material (NOT FOR PRODUCTION)

`sealbox-test.jks` is a throw-away Android signing keystore used by `scripts/gate_release.sh`
(gate G26) and by CI so that `flutter build apk --release` and `flutter build appbundle --release`
produce *signed* artifacts that `apksigner verify` / `jarsigner -verify` accept.

It is committed on purpose and **the passwords below are public**. Anything signed with it can never
be uploaded to Google Play, must never be shipped to a user, and gives no security whatsoever.
The production upload key is generated by a human and lives outside the repository — see
`docs/RELEASE.md` ("Store signing").

| | |
|---|---|
| file | `testing/keys/sealbox-test.jks` (PKCS12) |
| alias | `sealbox-test` |
| store password | `sealbox-test` |
| key password | `sealbox-test` |
| subject | `CN=Sealbox TEST signing key - NOT FOR PRODUCTION, OU=testing, O=Sealbox, C=GB` |
| certificate SHA-256 | `8F:AC:91:F8:84:9F:15:DE:67:53:1F:37:51:AA:7F:5C:D2:27:26:D6:90:80:25:3D:7A:C0:C4:F8:CF:00:67:51` |
| valid | 2026-10-27 → 2054-03-14 (10 000 days) |

Regenerate with exactly the same parameters (update the fingerprint above afterwards):

```bash
keytool -genkeypair -v -keystore testing/keys/sealbox-test.jks -storetype PKCS12 \
  -alias sealbox-test -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass sealbox-test -keypass sealbox-test \
  -dname "CN=Sealbox TEST signing key - NOT FOR PRODUCTION, OU=testing, O=Sealbox, C=GB"
```

Wiring: `app/android/app/build.gradle.kts` reads the properties file named by `$SEALBOX_KEY_PROPERTIES`,
else `app/android/key.properties` (git-ignored). Copy `app/android/key.properties.example` to use this
keystore by hand; `scripts/gate_release.sh` writes a temporary properties file under `target/` itself.
Debug builds (`flutter build apk --debug`, gate G10) never need any of this.
